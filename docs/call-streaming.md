# 通话重写（GPT 分支）

旧 `call.js` 的轮次逻辑、单语言本地 ASR / Worker、识别语言包下载和通话测试已替换。联系人音色、旧通话消息和浏览器中已下载的用户数据保留，不执行清库。

## 免费本地识别流程

- 语音识别改为 Vosk-Browser 0.0.8 + 官方小模型（中 / 日 / 英），均为 Apache-2.0。不再使用云端识别 API，也不读取旧 `callAsr` 密钥；不自动回退到任何付费识别服务。角色回复和 TTS 继续使用用户已有的配置，其服务商费用与本地识别无关。
- `assets/asr/` 提供完整运行库及模型，识别时仅访问酒馆自己的静态文件。压缩模型约中文 42MB、日语 48MB、英语 40MB，插件因此增加约 135MB。首次初始化需要解压；解压模型通过 IndexedDB 缓存，数据保存在当前浏览器，不上传录音。
- `local-speech.js` 一次只保留一种语言的 Worker；语言切换时释放旧 Worker。各语言独立挂载 IDBFS，避免把已缓存的全部模型都读入内存。
- 输入圆盘默认上中文、右日语、下英语、左键盘，四个位置可以重新安排。拖动松手选择，中心区域 / 取消手势不提交；也支持点选。角色语言在接通时从聊天设置取一次，整通固定，不跟随输入语言改变。
- 手动选择输入语言，避免把相似发音猜到其它语言。本地小模型不支持自动中日英混合检测，之前的自动模式不再显示为可用。正在说话时切换语言，当前句仍使用旧语言，下一句才准备新模型。
- 麦克风开启回声消除、降噪和增益控制，保留开口前 .6 秒。模型持续接收约 80ms 的音频块，返回可修改的草稿；最终端点结果可以修正前文。通过单独的 `final` 标记区分真正的整句收尾，防止旧端点结果提前确认。
- 人声触发后立即显示「正在收音…」，停顿后显示「正在确认…」。完整句停顿约 .42 秒、无标点约 .72 秒，明显未完句约 1.35 秒；角色仍可通过 WAIT 判断继续等用户。不额外调用聊天模型猜改用户原话。
- 没有麦克风权限、模型不可用或设备太慢时，可切到键盘，借系统输入法语音输入后发送；不会暗中调用云端识别。
- `llm` 请求流式、低思考。稳定台词一到就合成，最多预合成领先当前播放位置两句。旧连接若只能整段返回，首声延迟仍由该连接决定。

## 语音和情绪

`EMO: happy` 等标记与台词分开，标记不进字幕，也不作为普通文字朗读。MiniMax 映射 `voice_setting.emotion`，`gpt-4o-mini-tts` 映射 `instructions`，Eleven v3 映射支持的声音标签。其它引擎保持原文，靠所选音色和文本节奏表达，不发送虚构的通用情绪字段。

| 服务 | 通话音频路径 |
| --- | --- |
| OpenAI 兼容 | `response_format: pcm`，24kHz，HTTP 音频块到达就排程 |
| ElevenLabs | `/stream?output_format=pcm_24000`；账号与服务端须支持此格式 |
| MiniMax 国内 / 国际 | SSE、32kHz PCM、hex，验证成功结束事件；不重复播放最终汇总 |
| Fish / MiMo / Index / 火山等既有渠道 | 复用现有逐句 Blob 合成；与下一句合成重叠，不声称是 PCM 全链路流式 |

不在部分声音已播放后偷偷重试另一份回复。接口报错明确结束本轮，保留已说前缀和未说内容，用户可以继续说话。某个 OpenAI 兼容服务若不支持 PCM，会报错，不暗中增加请求或收费。

`call-audio.js` 每通电话共用一个 AudioContext。启动缓冲 .12 秒、排程提前量 .025 秒；短句已收完时直接播放。PCM 支持任意网络分块，raw 适配器保留奇数字节尾部，最终不完整采样报错。句子完成必须是传输正常结束且所有节点实际 `onended`，不能以下载完成代替。

## 打断、记录与记忆

- 播放时连续较强的声音约 .16 秒先压低角色音量；约 .38 秒确认插话并取消生成、合成、播放；短附和结束后恢复音量。思考期间约 .22 秒继续讲话也会取消旧轮。
- `AbortController` 和轮次身份一起阻止旧文本、音频、权限回调复活。挂断停止所有音轨、音频节点和计时器。没权限时显示真实错误并开放键盘输入，不把输入法模式冒充直接收音。
- 双方原文显示在屏幕。角色台词随播放显现，通话记录只保存已经显示 / 已经说到的前缀；未说内容放到独立 `pending`，下轮提示模型结合新问题自然接上，不重复旧话。
- **没有词级对齐数据时，播放中的字幕位置按音频时钟和文字长度估算**，中断点可能偏几个字；完整播放的句子准确确认。PCM 未收完时使用保守时长估算，不能把第一块音频当整句播完。
- 每轮重新读取 `sysCtx` 的当前角色、世界书与正文、当前联系人的最近消息、旧事关键词召回及当前电话记录，取消旧的整通电话冻结上下文。受设置的剧情条数 / 上下文预算限制，不声称无限记忆。
- 每条用户话语和每句已播完台词都更新同一条通话消息并调用 `saveD`，不等挂断才保存。切换酒馆聊天后结束旧电话，绝不调用新聊天的保存接口写旧记录。

## 验证与边界

运行 `node tests/run.cjs callflow callear call calllocal cssname`，涉及共用 TTS 再运行 `prov cset e2e`。`calllocal` 使用真实本地模型和录音、阻断外网；其它通话测试模拟模型和合成接口，不调用用户密钥。

`inCall().metrics` 暂存识别完成、首稳定台词、首音频到达、首排程、播放结束时间，用于比较实际连接路径；首排程不等于物理扬声器已发声。未在安卓 TauriTavern 真机和用户服务商实测前，不给毫秒级响应收益承诺。

浏览器或宿主必须授予麦克风权限。RMS 检测加浏览器回声消除并非神经 VAD；外放大音量、强噪声、录屏抢占麦克风仍需要真机验收。TTS 情绪、跨语言准确性和网络首声等待依赖模型、音色、服务商和设备。


## 本地识别边界

Vosk 小模型是免费离线选择，不保证达到手机输入法所用的大模型准确率；可能认错同音词，整句修正也不保证总是更准确。Chrome 与安卓 WebView 的速度取决于 CPU、内存和录音权限。测试真实录音只能证明模型可工作和逐步返回字幕，不代替用户真机测试。
