# 时间字体

锁屏时间 / 桌面「时间」小组件用的字体，全部来自 Google Fonts，SIL Open Font License 1.1，可以免费商用、可以修改再分发。
为了小，只截取了数字、冒号和几个标点。

| 文件 | 字体 |
|---|---|
| clk-nunito | Nunito |
| clk-baloo | Baloo 2 |
| clk-fredoka | Fredoka |
| clk-rubik | Rubik |
| clk-outfit | Outfit |
| clk-quicksand | Quicksand |
| clk-varela | Varela Round |
| clk-bebas | Bebas Neue |
| clk-serif | Cormorant Garamond |
| clk-playfair | Playfair Display |
| clk-dmserif | DM Serif Display |
| clk-pacifico | Pacifico |
| clk-shrikhand | Shrikhand |

另外在「主题 → 锁屏时间」里可以上传自己的字体文件（.ttf / .otf / .woff），只存在自己浏览器里，不会进仓库。

- `px-eye.woff`：缝合怪像素字体 Fusion Pixel 12px（TakWolf，SIL OFL 1.1，见 FUSION-PIXEL-OFL.txt），只截了窥探之眼片头用到的几十个字。
