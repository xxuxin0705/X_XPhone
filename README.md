# 📱 小手机 Mini Phone（SillyTavern 扩展）

一个悬浮在酒馆界面上的小手机，内置两个应用：**聊天** 和 **设置**。

## 安装

把整个 `mini-phone` 文件夹放到下面任一位置，然后刷新酒馆：

- `SillyTavern/public/scripts/extensions/third-party/mini-phone/`（所有用户可用）
- `SillyTavern/data/<你的用户名>/extensions/mini-phone/`（新版酒馆，仅当前用户）

刷新后右下角会出现 📱 按钮。按钮和手机都可以拖动（手机拖顶部状态栏）。
扩展面板里有「📱 小手机」可以开关插件、重置位置。

## 两种模式

| | 线上模式 | 正文联动 |
|---|---|---|
| 正文角色发的手机消息进入手机 | ✅ | ✅ |
| 你在手机里的回复让正文角色知道 | ❌ | 仅限打开了「同步到正文」的对话 ✅ |

联动模式下，在对话右上角 `⋯` → 联系人资料 → 打开 **同步到正文**，该对话最近 N 条记录会注入正文提示词。

## 正文 → 手机

插件会在提示词里告诉正文 AI 使用这个格式发手机消息（设置里可关闭）：

```
[手机消息|发送人|内容]
[手机图片|发送人|画面描述]
```

收到含这种格式的正文后，消息会自动进入手机；发送人不在通讯录里会自动新建联系人。
想让正文里不显示这些标签，可以用酒馆的「正则」扩展把它们替换或隐藏（只影响显示，不影响插件读取）。

## 联系人

- **自动**：联系人列表右上角 ✨，AI 会读角色卡、世界书和最近剧情，补充通讯录。
  也可以在设置里填「自动识别联系人」= N，每 N 条正文自动扫描一次。
- **手动**：联系人列表右上角 ＋。
- 打开聊天时会自动把当前角色卡加为联系人（人设留空则使用角色卡）。
- 联系人和聊天记录按 **酒馆聊天** 保存，切换聊天会切换通讯录。

## API 设置（手机 → 设置）

- **聊天**：可用「酒馆当前 API」，或自定义 OpenAI 兼容接口（地址填到 `/v1`，如 `https://api.openai.com/v1`）。
- **生图**：OpenAI 兼容 `/images/generations`。开启后角色发的 `[图片:…]` 会自动生成，你也可以用 📷 把输入框里的描述生成照片发出去。
- **TTS**：OpenAI 兼容 `/audio/speech`。对方消息悬停后点 🔊 朗读，每个联系人可单独设音色。

## 注意

- 自定义 API 是从浏览器直接请求的，若接口不允许跨域（CORS）会失败，可改用支持跨域的中转地址。
- 生图如果返回 base64，图片会存进聊天文件，图多了文件会变大。
- 「酒馆当前 API」依赖 `generateRaw`，太旧的酒馆版本请改用自定义 API。
