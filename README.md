# 小手机 Phone · SillyTavern 扩展

## 安装
把整个 `st-phone` 文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`，刷新酒馆即可（或用 扩展→安装扩展 填 git 地址）。

## 结构
```
index.js      入口：外壳、悬浮窗/魔法棒、酒馆事件（收到消息→识别剧情时间 & 线上事件）
core.js       核心：设置/数据存储、页面栈、表单绑定、AI(聊天/生图/TTS)+日志、世界书、正文注入
desk.js       桌面：多页网格、Dock、文件夹、小组件、长按编辑拖拽
lock.js       锁屏：上滑解锁、4位数字 / 手势密码（初始备用密码 0000 永远有效、不能改）
lockfx.js     动态锁屏场景：光之教堂、樱花飘落、初雪、小雨、爱丽丝仙境、红线（纯 Canvas 绘制）
apps/settings/settings.js  设置（API、联动模式、时间、上下文与世界书、显示方式、日志、数据）
apps/chat/chat.js          聊天 App 主体（消息列表、通讯录、动态、我、AI生成联系人）
apps/chat/talk.js          聊天窗口（回复协议、翻译、拍一拍、表情包、表情回应、引用、撤回、聊天设置）
apps/chat/data.js          聊天数据（联系人/群/消息的增删改、剧情同步）
apps/theme/theme.js        主题（桌面主题、壁纸、小组件、气泡、头像框、表情包、图标、自定义CSS）
```

## 要点
- 上传的图片 / 视频、AI 生成的图都存在 `SillyTavern/data/<用户>/user/images/XPhone/`，删掉消息、表情包、头像、壁纸、联系人或整个聊天时，没有别处再用到的文件会一起删除。
- 锁屏：设置 → 锁屏与密码；锁屏壁纸在 主题 → 锁屏壁纸 · 动态 里切换，也可以上传 5 秒内的视频。
- 手机数据（联系人/聊天/动态）存在当前酒馆聊天的 metadata 里，每个聊天各一份；API、主题、素材、桌面为全局设置。
- 正文联动：AI 回复里出现「发消息 / 拉群 / 加好友 / 朋友圈…」关键词时自动同步到手机并弹窗；
  标记“注入正文”的手机聊天会通过扩展提示词注入（深度2）。线上模式不注入。
- 桌面：长按图标/空白处进入编辑；拖到另一个图标中央 = 建文件夹，拖到边缘 = 换页；编辑模式点小组件可修改。
- 自定义气泡 CSS 可用类名：`.bub` 气泡、`.me` 我方消息、`.av` 头像、`.cv` 聊天区、`.mn` 昵称、`.tr` 译文。
- 小组件 HTML 可用变量：`{{time}} {{date}} {{md}} {{week}} {{weekEn}} {{user}} {{char}}`。


- 横版 CCD 相机：桌面长按 → 小组件 → 横版 CCD 相机，默认 4×2，也可改成 2×1；支持经典银／香芋紫／樱花粉／自定义色、照片或循环视频、贴纸、透明或自定义背景。设置实时生效，关闭即可保留。
